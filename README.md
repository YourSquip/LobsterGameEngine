Дипломная работа на тему "Создание игрового двухмерного движка для разработки игр с видом сверху с использованием Qt"

В данный момент в движке можно:
- рисовать карту с помощью заготовленных спрайтов
- создавать объекты и назначать им кастомные спрайты
- назначать объекты, с которыми можно взаимодействовать и объекты, которые могут взаимодействовать с другими
- назначать объект игрока, который можно контролировать клавишами (up,down,left,right,enter)
- переключаться между игровым режимом и режимом редактирования игры
